Packaging only. This pack does **not** launch, enable, or fund any campaign.

Use this folder as the canonical brief, copy, checklists, and launch instructions for the first paid flight. Reuse the existing **v3** creatives. Do not rebuild PNGs that already match platform sizes and the approved offer.

## Offer (approved)

- Product: LTS Inventory
- Destination: https://inventory.lit-solutions.tech
- Seven-day Essentials trial
- No card required
- $49 per month after the trial

## How to use this pack

1. Read `01-campaign-brief.md`.
2. Paste copy from `copy-to-paste.txt` or the channel files (`02`–`04`).
3. Upload only the v3 assets listed as **use** in `06-asset-manifest.md`.
4. Apply names and UTMs from `08-utm-and-campaign-naming.md`.
5. Complete `09`–`11` before a human owner enables spend.
6. Follow `12-manual-launch-first-flight.md` and **stop before enable/publish/fund**.
