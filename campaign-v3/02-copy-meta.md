# 2. Meta-ready copy variants

Platforms: Facebook and Instagram, using Meta Ads Manager.

Limits used by this pack (see `05-headline-description-limits.md`):

| Field | Limit |
|---|---|
| Primary text | 125 characters recommended before truncation; keep full variants under 200 |
| Headline | 40 characters |
| Description | 30 characters |
| Destination | https://inventory.lit-solutions.tech |
| Display URL | inventory.lit-solutions.tech |

Counts below are characters, including spaces and punctuation.

Recommended CTA in Ads Manager: **Sign up**. Alternate: **Learn more**.

## Primary text

Use A or C as default. Use B when pairing with `linkedin-number.png` language or spreadsheet-themed stills. Use D when the placement shows the full caption.

Know what you have — and where it went. LTS Inventory tracks products, lots, serials, receiving, and stock history. Start a 7-day Essentials trial. No card. $49 per month after the trial.

A spreadsheet can tell you a number. It cannot tell you why. LTS Inventory is inventory you can explain. Start a 7-day Essentials trial. No card required.

Know what you have. Know where it went. Start a 7-day Essentials trial of LTS Inventory. No card. $49/mo after.

## Do not paste (superseded v3 lines)

- Any line that lists **fulfillment** as an Essentials-trial capability
- “A spreadsheet can tell you 47” (rhetorical number that can be read as a statistic)
- Veteran-owned, Montross, customer counts, savings, or compliance claims
