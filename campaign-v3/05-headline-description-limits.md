# 5. Headline and description limits

These limits match the existing in-repo campaign documentation (`ads/copy-to-paste.txt` used 40 / 30 / 90) and the fields this pack fills. If an ad console shows a tighter counter, the console wins — do not submit over-limit text.

All counts in this pack are characters, including spaces and punctuation. Copy is ASCII plus a single em dash (`—`) in two Meta/LinkedIn/Google lines. Avoid emoji, curly quotes, and trademark symbols.

## Meta (Facebook / Instagram link ads)

| Field | Pack limit | Notes |
|---|---|---|
| Primary text | 125 recommended; keep variants ≤200 | Feed truncates; full text remains available after “See more” |
| Headline | 40 | Same cap as v1 paste sheet |
| Description | 30 | Link description under the headline |
| Image text | Prefer little or no extra overlay | v3 stills already contain headlines |

## LinkedIn (single-image sponsored content)

| Field | Pack limit | Notes |
|---|---|---|
| Intro text | 150 recommended; 600 maximum | Intro C is written to sit under the “see more” fold |
| Headline | 70 | All pack headlines are ≤40 and therefore safe |
| Introductory offer line | Include trial + no card + $49/mo when the intro has room | Required for this flight |

## Offer lines that already fit

Use these when a field is short and the offer must still appear:

| Line | Count | Fits |
|---|---|---|
| 7-day trial. No card. | 21 | Meta headline, Meta description, Google headline, Display short |
| 7 days free. $49/mo after. | 26 | Meta headline, Google headline |
| $49/mo after trial | 18 | Google headline |
| No card. $49/mo after. | 22 | Meta description |
| 7-day Essentials trial. No card. | 32 | LinkedIn headline (70) and Meta headline (40); too long for Google headlines (30) |

`7-day Essentials trial. No card.` = 32 characters — allowed on LinkedIn (70) and Meta headlines (40); too long for Google headlines (30). Use `7-day trial. No card.` on Google.

## What this pack does not size

- YouTube / Demand Gen long copy
- Meta Advantage+ catalog fields
- LinkedIn conversation ads, document ads, or lead-gen forms
- Google callouts, sitelinks, or structured snippets

Do not invent those extensions for the first flight.
