# 11. Preflight checklist

Complete this before a human owner turns any ad **on**. This pack does not itself launch or fund campaigns. Leave every campaign **paused / draft**.

## Pack integrity

- [ ] Working from `campaign-v3/` on branch `docs/campaign-pack-v3` (or the merged equivalent)
- [ ] Creatives uploaded from `ads-v2/` or `lts-inventory-ads-v3.zip`, not v1/v2 archives
- [ ] `landscape-fulfill.png` is **not** attached
- [ ] Paste sheet is `campaign-v3/copy-to-paste.txt` (fulfillment lines removed)

## Offer and destination

- [ ] Final URL host is `inventory.lit-solutions.tech`
- [ ] Display URL is `inventory.lit-solutions.tech`
- [ ] Copy includes seven-day Essentials trial, no card, and $49/mo after (or the short equivalents that still name those facts)
- [ ] Logged-out click-through still starts a no-card trial (landing-page checklist signed)
- [ ] No Operations/Control/Enterprise prices in the ads

## Channel copy limits

- [ ] Meta headlines ≤40, descriptions ≤30
- [ ] LinkedIn headlines ≤70
- [ ] Google RSA headlines ≤30, descriptions ≤90
- [ ] Google Display short headlines ≤30, long headlines and descriptions ≤90
- [ ] Console character counters agree (console wins if it disagrees)

## Naming and UTMs

- [ ] Campaign names follow `LTS-Inv_Essentials-Trial_v3_<Channel>`
- [ ] UTMs match `08-utm-and-campaign-naming.md`
- [ ] `utm_content` equals the asset stem
- [ ] No PII in URLs

## Accounts and billing (do not complete spend)

- [ ] Ads run from Little Technical Solutions LLC / LTS Inventory accounts, not a personal test account
- [ ] Payment method is **not** attached for the purpose of this packaging work
- [ ] Daily budget, bid, and end date remain unset **or** saved with the campaign **paused**
- [ ] No campaign is set to Active / Enabled / Publishing

## Tracking honesty

- [ ] No conversion action is advertised as “installed” unless it is verified on the **app** host
- [ ] First-flight KPI, if any, is clicks or landing-page arrivals — not a fabricated ROAS target

## Policy and creative quality

- [ ] Screenshots are actual product UI (v3 bake)
- [ ] No before/after savings, no “guaranteed,” no competitor defamation
- [ ] Scan creative does not promise a hardware scanner
- [ ] Previewed on mobile and desktop placements in Ads Manager / Google Ads / Campaign Manager
